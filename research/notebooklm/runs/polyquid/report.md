# Polyquid Project Research Brief

**1. Project Overview and Operating Model**
*   **Project Identification:** Polyquid is categorized as a "Prop Trading Challenge."
*   **Current Status:** As of the audit date 2026-08-16, the project is in a pre-operational waitlist phase.
*   **Market Claims:** Documentation explicitly states the platform provides access to "Every market" via its "One challenge" model.
*   **Operational Infrastructure:** The project identifies as "Built on **Hyperliquid** & **Polymarket**." 
*   **Operating Model Ambiguity:** The specific nature of the trading environment—specifically whether it utilizes simulated paper-trading or live capital—is currently not disclosed in available sources.

**2. Trader Lifecycle: From Entry to Payout**
*   **Entry Phase:** Public access is limited to "Join the waitlist," "Discord" community entry, and following official "X" channels.
*   **Evaluation Phase:** Platform documentation identifies a singular "One challenge" system as the gateway to the "Every market" claim.
*   **Post-Evaluation Phases:** There is zero documentation regarding the transition from successful challenge completion to funded status.
*   **Operational Void:** Mechanics for capital allocation, risk enforcement protocols, and compensation distribution are not documented. The trader lifecycle currently terminates at the waitlist/community acquisition point.
